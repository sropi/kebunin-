# Kebunin Grocery Mobile App - Stitch UI & Code

Proyek UI dan kode frontend untuk aplikasi mobile **Kebunin Grocery Mobile App**, diunduh langsung dari Google Stitch.

**Project Details:**
- **Title:** Kebunin Grocery Mobile App
- **Project ID:** `2689762860264601831`

- **Design System:** Verdant Harvest (`DESIGN_SYSTEM.md`)
- **Primary Colors:** Forest Green (`#245C3A`), Leaf Green (`#78A85A`), Warm Cream (`#F8F6EF`)
